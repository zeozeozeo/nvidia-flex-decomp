# 046 `cs_5_0` — CalculateBounds (not reconstructed)

## Interface
- `cbuffer consts` `cb0[24]` immediateIndexed (`KernelParams` prefix through `kInvDt`)
- SRV: `t2`/`t3` structured stride 16 (`boundsLower`, `boundsUpper` inputs); `t0`,`t1` unused
- UAV: `u2` structured stride 12 (float3 bounds), **`dcl_uav_structured_opc u7, 256`**
- groupshared: `g0` 12 B × 4; thread group 128×1×1
- entry: `SV_DispatchThreadID` + `SV_GroupThreadID`

## Algorithm
Reduces the per-thread bound contributions through groupshared memory (`g0`, 4 slots), then
writes the combined lower/upper bounds to `u2` and appends the same values to the NVAPI
extension command buffer `u7` (`imm_atomic_alloc` + `store_structured`, opcode `3`).
121 `u7` references.

## Blocker (hard, toolchain)
`dcl_uav_structured_opc u7, 256` is unreachable from `vkd3d-shader 2.1` HLSL (no append/consume
buffer type, no counter method — `E5030`/`E5005`). The binding set can never match, so the
shader is documented instead of written.
