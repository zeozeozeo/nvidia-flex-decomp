# 042 `cs_5_0` — SolveShapes (plastic variant)

## Interface
- no constant buffer
- SRV `t0..t5` structured stride 4 (`rigidOffsets`, `rigidIndices`, `rigidCoefficients`,
  `rigidPlasticThresholds`, `rigidPlasticCreeps`, `reverseLookup`), `t6`/`t7` stride 16
  (`oldPositions`, `localNormals`)
- UAV `u0` raw (`InterlockedFloat::accum`), `u1` 12 (`localPositions`), `u2`/`u3`/`u5` 16
  (`newPositions`, `rotations`, `normals`), `u4` 12 (`translations`)
- groupshared `g0` 12, `g1` 12, `g2` 36, `g3` 4, `g4` 4, `g5` 12×64, `g6` 16
- thread group 64×1×1; entry `SV_GroupID` (shape) + `SV_GroupThreadID`

## Algorithm
1. tree-reduce the shape's `newPositions[reverseLookup[rigidIndices[..]]]` into `g0`; if the
   average matches the stored translation within 1e-5 use the stored translation;
2. `usePlastic = rigidPlasticCreeps[shape] != 0` — for each particle compare the motion
   `newPos - oldPos` against `rigidPlasticThresholds[shape]` and raise the group flag;
3. three tree reductions of `d * localPositions.xyz` build the covariance columns;
4. thread 0 sets `mass = flag ? 1 : 0` (the flag is raised when *no* particle exceeded the
   threshold in the bytecode: `g3` is pre-cleared and set to `0xffffffff` on exceed, then
   `g4 = (g3 == 0) ? 0 : 1`), runs four rotation-refinement steps and publishes the quaternion
   in `g6`, `rotations[shape]` and the average in `translations[shape]`;
5. each particle: `target = avg + Rotate(q, localPos)`; if `mass > 0` the local position is
   re-expressed in shape space via the inverse rotation and the coefficient blend
   `rigidCoefficients[shape] * (1 - mass)`; normals are rotated and stored; the delta
   `[-mass * (newPos - target), 1]` is accumulated into `u0` with the same
   `imm_atomic_cmp_exch` retry loops as the original.

## Inferences
- `Rotate(q, v)` is transcribed from the bytecode expansion
  `v*(w*w-1) + 2*q.xyz*dot(q.xyz,v) + 2*w*cross(v,q)`; the inverse rotation uses `q.xyz`
  negated with `q.w` unchanged (the bytecode negates only the vector part).
- The rotation extraction is the iterative axis/trace update (summed cross products divided by
  `|trace|`, half-angle `sincos`, quaternion composition). The four-wide cross accumulation of
  the bytecode is written as three `float3` crosses; opcode multiset differs (advisory).
- `g3 == 0` is read as "no particle exceeded the plastic threshold", which yields the
  `mass = 1` branch — the bytecode stores `0` into `g3` in pass 0 and `~0` on exceed.
