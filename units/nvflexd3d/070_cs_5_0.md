## Status: NOT RECONSTRUCTED (hard limit)
The shipped shader indexes the constant buffer non-uniformly
(`dp3 r1.w, r0.xyzx, cb0[r1.z + 0].xyzx`, the global `kPlanes` loop), which makes fxc emit
`dcl_constantBuffer cb0[32], dynamicIndexed`. vkd3d-shader's SM5 back end never sets that flag:
it printed `immediateIndexed` for all three probe forms tried (loop-variable index, UAV-derived
index, constant-buffer-derived index, all of which it emits as `cb0[rX + 0]`). Since the gate
compares the declaration text, this index cannot match. No HLSL file is written.

A partial interface-correct body was drafted and discarded (see this note's history) rather than
committing a shader that cannot be gated.
