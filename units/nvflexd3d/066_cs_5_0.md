# 066 `cs_5_0` — ApplyDeltas

## Interface
- `cbuffer consts` (b0, 29 registers)
- `ByteAddressBuffer deltas` (t0, `dcl_resource_raw`)
- `RWStructuredBuffer<float4> newPositions` (u0, stride 16)
- thread group 256x1x1

## Algorithm
`delta = deltas.Load4(tid*16)`; with `kRelaxationMode != 0` the weight is
`1 / max(delta.w * kSOR, 1)`, otherwise `kRelaxationFactor`; the xyz of the new position
are `newPosition + delta.xyz * weight`, `w` is preserved.

## Inference
- `cb0[25].z` is `kRelaxationMode`, `cb0[22].x` is `kSOR`, `cb0[28].w` is
  `kRelaxationFactor` (offsets 404, 352, 460 of the parameter block).
- The delta buffer is a raw UAV-style SRV because the host writes it from a
  ByteAddress UAV in the solve kernels.
