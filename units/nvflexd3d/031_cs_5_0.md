# 031 `cs_5_0` — SolveInflatableVolume (NVAPI variant)

**Status: blocked (not reconstructed) — toolchain limit.**

## Interface
- no constant buffer
- `StructuredBuffer<Inflatable>` (t0, stride 16), `positions` (t1, stride 16), `reverseLookup` (t2),
  `indices` (t3), `RWStructuredBuffer<float> lambdas` (u0, stride 4)
- **`dcl_uav_structured_opc u7, 256`** (`g_NvidiaExt`)
- `groupshared`: 16 B, 4 B, 12 B, 4x16, 12x16; thread group 512x1x1

## Algorithm
The NVAPI cross-lane variant of 033/035: 81 references to `u7`, 40 of them `imm_atomic_alloc`,
plus 45 `store_structured`. The per-slice corner-position and corner-volume reductions are
published through the NVAPI extension buffer instead of the AMD atomic-memory reads (033) or
the shared-memory power-of-two walk (035); thread 0 still writes the lambda for the group.

## Blocker (hard, toolchain)
`dcl_uav_structured_opc` is not expressible in this front end (see 027). Recorded as a
toolchain limit, not a reconstruction gap.
