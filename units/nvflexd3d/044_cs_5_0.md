# 044 `cs_5_0` — SolveDensities (delta accumulation)

## Interface
- `cbuffer consts` `cb0[24]` immediateIndexed (`KernelParams` through `kInvDt`)
- SRV `t0`/`t1` stride 4 (`contacts`, `contactCounts`), `t2` 16 (`sortedNewPositions`),
  `t6` 16 (`sortedPositions`), `t7` 16 (`sortedNormals`)
- UAV `u0` raw (`deltas`), float4 per particle
- thread group 256×1×1

## Algorithm
Per particle: skip if `newPositions.w == 0` (zero the delta slot), else walk the neighbour list
(`contacts[i]`, stride `kNumParticlesAligned`). A neighbour contributes when
`0 < |d|² <= kRadiusSq` and `kSolidRestDistance >= |d|`; the direction is either the normal of
the neighbour with the smaller `w`, its reflection about `d/dist` (when `dot > 0`), or the
plain direction when `w == 0`. The push is `-(wratio * (dist - kSolidRestDistance)) * n`. When
`kDynamicFriction > 0` the tangential part of `d - (pos - sortedPositions[n])` is removed with
a static / sliding decision driven by `kStaticFriction` and `kParticleFriction`. `w` accumulates
the contact count; the 16-byte raw slot receives `(delta.xyz, count)`.

## Inferences
- `kParticleFriction` is used for the sliding ramp and `kStaticFriction` for the stick limit, as
  read from `cb0[17].x/.y` at the exact instruction sites.
- The delta is written as raw `uint4` through `asuint`; the value bytes match the original
  float store.
