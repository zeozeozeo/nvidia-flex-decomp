# 008 `cs_5_0` — ComputeTotalBounds

**Status: blocked (not reconstructed).**

## Interface
`dcl_uav_raw u7`, RDEF name `AmdDxExtShaderIntrinsicsUAV` — the AMD shader-intrinsics
buffer, plus the usual bound buffers and a `groupshared float3` reduction array.

## Algorithm evidence
The kernel performs the block-wide min/max tree in groupshared memory (as in 003/004/021)
and then publishes the result with eight `imm_atomic_cmp_exch` instructions per component
against byte offsets `0x50402204`-style opcode addresses (e.g. `1346379524`,
`1344282372`, `1343233796`, ...), i.e. an atomic min against the AMD extension UAV.

## Blocker
`RWByteAddressBuffer` in the vkd3d-shader SM5 front end exposes only `Store`/`Store2`
(verified: `Load`, `Load4`, `InterlockedAdd` and `InterlockedCompareExchange` all fail
with `E5005: Method ... is not defined on type 'RWByteAddressBuffer'`). The read-modify-write
atomic sequence that defines this kernel therefore cannot be expressed, and no separate
SRV may be added without changing the binding set. Blocked rather than faked.
