# 079 `cs_5_0` — CalculateBounds

## Interface
- `cbuffer consts` (b0, 24 registers)
- `StructuredBuffer<float4> positions` (t2, 16), `predicted` (t3, 16)
- `RWStructuredBuffer<float4> boundsMin` (u0, 16), `boundsMax` (u1, 16)
- `groupshared float3 sBounds[128]`, thread group 128x1x1

## Algorithm
Same contract as 065 but with a shared-memory tree instead of raw-UAV atomics: min pass over t2,
max pass over t3, each a 7-step `s >>= 1` reduction over 128 lanes; lane 0 writes
`boundsMin[gid]`/`boundsMax[gid]` with `w = 0`.

## Inference
- The shipped bytecode bounds the global thread id by `ceil(kNumParticles / 128)`
  (`iadd r0.x, cb0[23].x, 127; ushr r0.x, r0.x, 7`), which is reproduced verbatim even though it
  makes the per-particle read index a chunk index (`tid.x`) rather than a particle index.
- The min result is broadcast through shared memory (`ld_structured r2.xyz, 0`) before the max
  pass overwrites the array, which the reconstruction keeps as a saved `groupMin`.
