# 059 `cs_5_0` — ClearInt

## Interface
- `cbuffer ClearInt::consts { int gLength; int gValue; int _pad1; int _pad2; }` (b0, 16 bytes)
- `RWStructuredBuffer<int> buf` (u0, stride 4)
- thread group 256x1x1

## Algorithm
`if (tid < gLength) buf[tid] = gValue;`

## Inference
- The four trailing constants are the fxc padding members `_pad1`/`_pad2` of the
  constant buffer; only the first two are read.
