# 056 `cs_5_0` — SolveContacts

## Interface
- `cbuffer consts` `cb0[32]` immediateIndexed (full 512-byte `KernelParams`)
- SRV `t0` 4 (`collisionCounts`), `t1`/`t2`/`t3` 16 (`collisionPlanes`, `prevPositions`,
  `collisionVelocities`)
- UAV `u0` 16 (`positions`, read+written), `u1` 16 (`deltas`, read+written)
- thread group 256×1×1

## Algorithm
Per particle (skipped when `positions.w == 0` or the count is 0): iterate the collision planes
at `tid * kMaxContactsPerParticle + k`, `dist = dot(pos, n) + d`, `pen = dist - kCollisionDistance`.
Adhesion subtracts `dist * kAdhesion * n`. For `pen < 0` the particle is pushed by `-pen * n`;
when the plane has a normal and `kDynamicFriction > 0` the tangential part of
`(pos - prev) - collisionVelocity` is removed, with the stick test `|t|² < (pen*kStaticFriction)²`
and otherwise a `min(1, -pen*kDynamicFriction/|t|)` slide. If any contact fired,
`deltas[tid] += (delta.xyz, count)`.
