# 003 `cs_5_0` — ComputeTotalBounds (second level)

## Interface
- `cbuffer constBVH { int gNumItems; }` (b0)
- `StructuredBuffer<float4> readBoundsLower` (t2), `readBoundsUpper` (t3)
- `RWStructuredBuffer<float4> writeBoundsLower` (u0), `writeBoundsUpper` (u1)
- `groupshared float3[256]`, thread group 256x1x1

## Algorithm
`numGroups = (gNumItems + 255) >> 8`. Each thread loads the per-group bound (or `+FLT_MAX`
when past the group count) and the block reduces it with the classic 128→1 shared-memory
tree; the same is repeated with `-FLT_MAX` and `max` for the upper bounds. Thread 0 writes
`float4(min, 0)` / `float4(max, 0)` at `SV_GroupID`.
