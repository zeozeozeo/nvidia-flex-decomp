# 083 `cs_5_0` — RadixSortSortPairs

## Interface
- `cbuffer params` (b0, 2 registers)
- `Buffer<uint4> keySrc4` (t0), `Buffer<uint4> valSrc4` (t1), `Buffer<uint> counters` (t2)
- `RWBuffer<uint4> keyDst` (u0), `RWBuffer<uint4> valDst` (u1)
- `groupshared`: `sKey[1024]`, `sVal[1024]`, two 256-entry scans, `sDigitStart[16]`,
  `sDigitEnd[16]`, thread group 256x1x1

## Algorithm
A 4-bit pass: the group preloads its 16 digit boundaries from `counters`
(`counters[digit * gridDim.x + gid]` for the destination starts and
`counters[(gid + gridDim.x) * 16 + digit]` for the in-block starts), performs four stable 1-bit
partitions over the 1024 keys (`bit = passStart .. passStart+3`), then scatters the digit-ordered
block with `dest = sDigitStart[digit] + (i - sDigitEnd[digit])`.
