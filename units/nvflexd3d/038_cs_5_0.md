# 038 `cs_5_0` — ContinuousShockPropagation

## Interface
- `cbuffer consts` (b0, 24 registers)
- `StructuredBuffer<float3> bounds` (t0, stride 12)
- `RWStructuredBuffer<float4> positions` (u0, stride 16, read-modify-write)
- `groupshared float3` x2 (12 bytes each in the original)
- thread group 256x1x1

## Algorithm
Thread 0 selects the bound with the smaller `dot(kGravity, bound)` and stores it plus the
normalised gravity direction (zeroed when `|g|^2 == 0`) in group shared memory. After a
barrier each particle computes `s = dot(shockPoint - pos.xyz, shockDir) * kShockPropagation`
and scales its `w` by `exp(s)`.

## Inference
- The fxc pattern `mul x, 1.44269502` + `exp` is `exp(x)` (D3D `exp` is base 2), so the
  source expression is `exp(s)`.
- Only the `w` lane is written back (`store_structured u0.x, ..., l(12)`); the xyz are
  re-stored unchanged by the read-modify-write.
