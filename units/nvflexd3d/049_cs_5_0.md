# 049 `cs_5_0` — SolveShapes (not reconstructed)

## Interface
- no constant buffer
- SRV: `t0`/`t1`/`t2`/`t5` structured stride 4, `t7` stride 16
- UAV: `u0` raw (`InterlockedFloat::accum`), `u1` 12, `u2`/`u3`/`u5` 16, `u4` 12,
  **`dcl_uav_structured_opc u7, 256`**
- groupshared: `g0`/`g1` 12 B, `g2` 36 B, `g3` 12×1, `g4` 16 B
- thread group 32×1×1; entry `SV_GroupID` + `SV_GroupThreadID`

## Algorithm
32-thread variant of the SolveShapes pass (reduction width 32, single-slot groupshared
accumulator), writing shape contacts and NVAPI extension commands to `u7` (269 references,
opcode `3`).

## Blocker (hard, toolchain)
`dcl_uav_structured_opc` not emittable from `vkd3d-shader 2.1` HLSL (`E5030`/`E5005`).
Documented, not attempted.
