# 013 `cs_5_0` — CalculateKeyDeltas

## Interface
- `cbuffer constBVH { int gNumItems; }` (b0, 16 bytes, only 4 used)
- `Buffer<uint> keys` (t0, typed buffer), `RWStructuredBuffer<int> deltas` (u0, stride 4)
- thread group 256x1x1

## Algorithm
`if (tid < gNumItems - 1) deltas[tid] = keys[tid] ^ keys[tid + 1];`
XOR of adjacent sorted Morton keys — the radix-sort flag computation of
`MedianBVHBuilder::Build` (bvh.cu `CalculateKeyDeltas`).

## Inference
- The `Buffer<uint>` element type is taken from the `(uint,uint,uint,uint)`
  resource declaration; the stored value is a bitwise XOR, so signedness is irrelevant.
- The host launches `gNumItems - 1` threads; the shader also guards.
