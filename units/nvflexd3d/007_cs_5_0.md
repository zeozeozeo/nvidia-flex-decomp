# 007 `cs_5_0` — ComputeTotalBounds (final reduction)

## Interface
- `cbuffer constBVH { int gNumItems; }` (b0)
- `StructuredBuffer<float4> readBoundsLower` (t2), `readBoundsUpper` (t3)
- `RWStructuredBuffer<float3> totalLower` (u2), `totalUpper` (u3), `totalInvEdges` (u4)
- thread group 1x1x1 (single thread)

## Algorithm
`n = ((gNumItems + 255) >> 8 + 255) >> 8`. Starting from element 0, fold `min`/`max` over
`1..n-1`, store the totals and `1 / (upper - lower + 1e-4)`.

## Notes
Shaders 010 and 011 are the same kernel for other bound arrays (identical body, different
resource names); they were reconstructed the same way.
