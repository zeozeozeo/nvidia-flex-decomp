# 055 `cs_5_0` — UpdateTriangles (delta clear)

## Interface
- `cbuffer consts` `cb0[24]` immediateIndexed
- UAV `u0` raw (`UpdateTriangles::deltas`), 16 bytes per particle
- thread group 256×1×1

## Algorithm
`if (tid < kNumParticles) deltas.Store(tid * 16, 0)` — clears the per-particle delta
accumulator before the triangle pass.
