# 058 `cs_5_0` — CollideParticles

## Interface
- `cbuffer consts` `cb0[31]` immediateIndexed (through `kMaxNeighborsPerParticle`)
- SRV `t0`/`t1` 4 (`cellStarts`, `cellEnds`), `t2` typed `Buffer<uint>` (`indices`),
  `t3` 16 (`sortedNewPositions`), `t4` 16 (`restPositions`), `t5` 4 (`phases`),
  `t6` 12 (`bounds`, float3)
- UAV `u0` 4 (`contacts`), `u1` 4 (`contactCounts`)
- thread group 256×1×1

## Algorithm
Cell of the particle = `(int3)((pos - bounds[0]) * kInvCellEdge)`; scan the 3×3×3 neighbourhood,
each axis packed into 7 bits (`x` at bit 0, `y` at 7, `z` at 14 as in the bytecode's `bfi`
chain). For every particle `j` in a cell: skip self; the pair is tested when the particle has
phase bit `1<<21` set or the two group ids (`phase & 0xfffff`) differ; when phase bit `1<<20` is
set and the groups match, the pair is skipped if the **rest** positions are closer than
`kRadiusSq`. Accepted neighbours (`|p - q|² < kCollideParticlesRadiusSq`, up to
`kMaxNeighborsPerParticle`) are stored at `tid + n * kNumParticlesAligned`; the final count goes
to `contactCounts[tid]`.

## Inferences
- `myRest` is loaded unconditionally from `restPositions[indices[tid]]`; the original sinks the
  load behind `if (phase & 1<<21)` but uses the register in the flagged branch regardless.
- Bit fields 20/21 and the `0xfffff` group mask come from the literal `and` masks
  (`1048575`, `1048576`, `2097152`) in the assembly.
