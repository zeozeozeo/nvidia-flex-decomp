# 048 `cs_5_0` — UpdateTriangles (not reconstructed)

## Interface
- `cbuffer consts` `cb0[31]` immediateIndexed (through `kMaxNeighborsPerParticle`)
- SRV: `t0`/`t1` structured stride 16 (`sortedNewPositions`, `sortedVelocities`),
  `t2`/`t3` stride 4 (`reverseLookup`, `indices`)
- UAV: `u0` raw (`InterlockedFloat::accum`), `u1` stride 12 (triangle normals),
  **`dcl_uav_structured_opc u7, 256`**
- thread group 256×1×1; entry `SV_DispatchThreadID`

## Algorithm
Computes per-triangle normals from the sorted new positions and accumulates them into `u0`
(atomic float adds, `imm_atomic_cmp_exch`) and `u1`; additionally writes the NVAPI extension
commands (`imm_atomic_alloc` on `u7`, opcode `13` payload at offsets 0/76/92/108/140).
85 `u7` references.

## Blocker (hard, toolchain)
`dcl_uav_structured_opc` is not emittable from `vkd3d-shader 2.1` HLSL (`E5030`/`E5005`); the
binding check can never match. Documented, not attempted.
