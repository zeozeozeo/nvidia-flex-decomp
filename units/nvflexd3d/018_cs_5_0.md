# 018 `cs_5_0` — CalculateBounds (AMD extension path)

## Interface
- `cbuffer consts` (b0, 24 registers)
- `StructuredBuffer<int> activeIndices` (t0), `StructuredBuffer<float4> positions` (t1)
- `RWStructuredBuffer<float4> writeBoundsLower` (u0), `writeBoundsUpper` (u1)
- `RWByteAddressBuffer AmdDxExtShaderIntrinsicsUAV` (u7, `dcl_uav_raw`)
- `groupshared float3[128]`, thread group 128x1x1

## Algorithm
Same block-wide min/max as the plain `CalculateBounds` (021), but each component is pushed
through the AMD extension UAV's five vector-atomic opcode groups before being combined, and
thread 0 folds the four 32-lane partials and publishes the group bounds.

## Reconstruction note
Transcribed verbatim: `InterlockedCompareExchange(uav[addr], asuint(v.x), 0u, old)` over
the same five opcode addresses as 006/008/012; the reconstruction reproduces all 30
`imm_atomic_cmp_exch` instructions and the `dcl_uav_raw u7` declaration.
