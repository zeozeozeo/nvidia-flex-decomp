# 052 `cs_5_0` — SolveShapes (no plastic stage)

## Interface
- no constant buffer
- SRV `t0`/`t1`/`t2`/`t5` stride 4 (`rigidOffsets`, `rigidIndices`, `rigidCoefficients`,
  `reverseLookup`), `t7` 16 (`localNormals`); `t3`/`t4`/`t6` are not bound
- UAV `u0` raw (`InterlockedFloat::accum`), `u1` 12 (`localPositions`), `u2`/`u3`/`u5` 16,
  `u4` 12 (`translations`)
- groupshared `g0` 12, `g1` 12, `g2` 36, `g3` 12×64, `g4` 16
- thread group 64×1×1; entry `SV_GroupID` + `SV_GroupThreadID`

## Algorithm
Same as 042 minus the plastic stage: pass 1 averages the shape's positions (with the
1e-5 "keep stored translation" test), pass 2 builds `sum(d * localPos)`, thread 0 runs the four
rotation-refinement steps, and pass 3 rotates the normals and accumulates
`rigidCoefficients[shape] * -delta` plus a `+1` counter into the raw accumulator slot
`slot*16` with the original CAS loops. `localPositions` is only read.

## Inferences
- Because no plastic flag exists, the coefficient is applied unconditionally (no `1 - mass`
  blend) — matches `mul r5.xyz, r0.w, -r4.xyz` with `r0.w = rigidCoefficients[shape]`.
- The +1 counter write at offset 12 uses the same CAS loop with delta 1.0.
