# 036 `cs_5_0` — SolveInflatableVolume

**Status: reconstructed** — `recon/src/dx/shaders/036_cs_5_0__SolveInflatableVolume.hlsl`, gate `1/1`.

## Interface
- `cbuffer consts` (b0, 25 registers; uses `kDt` = `cb0[23].z` and `kMaxSpeed` = `cb0[24].y`)
- `StructuredBuffer<Inflatable>` (t0, stride 16), `positions` (t1, stride 16), `reverseLookup` (t2),
  `indices` (t3), `StructuredBuffer<float> lambdas` (t4, stride 4)
- `RWByteAddressBuffer accum` (u0, `dcl_uav_raw`); `groupshared int2`
- thread group 512x1x1; one thread group per inflatable

## Algorithm
Thread 0 publishes `{offset, count}`. Every thread reads the inflatable's lambda, then walks the
inflatable's triangles with stride 512: for each triangle it forms
`n = -(lambda * cross(p1 - p0, p2 - p0))`, clamps `|n|` to `kDt * kMaxSpeed`, and scatters
`n` onto all three corners with nine float atomics (`index * 16 + {0,4,8}`).

## Inference
- The same gradient vector is added to all three corners (the shipped code emits one cross
  product and reuses it); this is the shipped approximation, not a transcription slip.
- The clamp is `if (maxDelta^2 < |n|^2) n *= maxDelta * rsqrt(|n|^2)` — a direction-preserving
  length clamp at `kDt * kMaxSpeed`.
- Note this pass has no `u7`, unlike its NVAPI sibling 031.
