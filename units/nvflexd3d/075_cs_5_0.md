## Status: NOT RECONSTRUCTED (hard limit)
The shader reads the raw UAV: `ld_raw_indexable(raw_buffer)(mixed,mixed,mixed,mixed) r3.xyzw,
r0.x, u0.xyzw`. `RWByteAddressBuffer` in vkd3d-shader's SM5 front end exposes only `Store`/
`Store2`, so a raw-UAV load cannot be expressed. No HLSL file is written.

Evidence: `work/dxbc/NvFlexReleaseD3D_x64/075_cs_5_0.asm` (the `ld_raw_indexable` at the end of
the accumulating branch, and the `store_raw` beside it).
