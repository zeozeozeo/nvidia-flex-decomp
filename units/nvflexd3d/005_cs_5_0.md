# 005 `cs_5_0` — BuildHierarchy

**Status: blocked (not reconstructed).**

## Interface
`dcl_uav_structured_glc u0..u5` — six structured UAVs carrying the `glc`
(globally coherent) flag, plus `StructuredBuffer<float4> t2/t3`.

## Blocker
The `glc` UAV flag is a bytecode/state bit that has no HLSL spelling and the vkd3d-shader
front end never sets it for source-generated UAVs, so the declaration cannot be reproduced
(`dcl_uav_structured u0, 16` would be emitted instead of
`dcl_uav_structured_glc u0, 16`). The kernel is the two-phase `BuildHierarchy` reduction;
its algorithm is otherwise recoverable, but a reconstruction with the wrong coherence flag
changes the host's resource declaration, so it is blocked rather than approximated.
