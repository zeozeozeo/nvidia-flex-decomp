# 073 `cs_5_0` — Predict

## Interface
- `cbuffer consts` (b0, 25 registers)
- `StructuredBuffer<int> indices` (t0, 4), `StructuredBuffer<float4> positions` (t1, 16),
  `StructuredBuffer<uint> particleFlags` (t2, 4)
- `RWStructuredBuffer<float4> predictedPositions` (u0, 16), `RWStructuredBuffer<float3> velocities` (u1, 12)
- thread group 256x1x1

## Algorithm
`g = kGravity * kDt`; diffuse particles (`flags & 0x400000`) integrate `g * kBuoyancy`, others
`g`; the velocity is kept for inactive particles (`p.w <= 0`), clamped to `kMaxSpeed` by length,
written back to the in-place velocity buffer, and `predictedPositions = float4(p.xyz + v*dt, p.w)`.

## Inference
- `cb0[16].xyz` = `kGravity`, `cb0[14].w` = `kBuoyancy`, `cb0[24].y` = `kMaxSpeed`,
  `cb0[23].z` = `kDt` (offsets confirmed against the RDEF variable table).
