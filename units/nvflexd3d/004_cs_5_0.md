# 004 `cs_5_0` — ComputeTotalBounds (first level)

## Interface
- `cbuffer constBVH { int gNumItems; }` (b0)
- `StructuredBuffer<float4> itemLowers` (t0), `itemUppers` (t1)
- `RWStructuredBuffer<float4> writeBoundsLower` (u0), `writeBoundsUpper` (u1)
- `groupshared float3[256]`, thread group 256x1x1

## Algorithm
Same block-wide min/max tree as shader 003, but over the item bounds directly:
`tid < gNumItems` selects the element, otherwise `+FLT_MAX` / `-FLT_MAX` is used, and
thread 0 stores the group result at `SV_GroupID`.
