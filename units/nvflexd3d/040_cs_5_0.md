# 040 `cs_5_0` — SpringsParticleRange

## Interface
- `cbuffer SpringsParticleRange::consts { int gNumSprings; }` (b0, 16 bytes)
- `Buffer<uint> ids` (t0), `RWStructuredBuffer<int> starts` (u0, stride 4), `ends` (u1, stride 4)
- thread group 256x1x1

## Algorithm
Over the `2 * gNumSprings` half-edge ids: emit the run boundaries of equal ids into
`starts`/`ends` (first id starts at 0, every id change closes the previous run and opens
the new one, the last thread closes the final run at `2 * gNumSprings`).

## Inference
- Structurally identical to `CreateGrid` (063); this is the same scan over the
  `Springs::*.ids` array produced by `SpringsGenerateIndices` (053).
