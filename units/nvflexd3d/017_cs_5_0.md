# 017 `cs_5_0` — ClampDiffuseParticleCount

## Interface
- `cbuffer consts` (b0, 28 registers = 448 bytes of the 512-byte parameter block)
- `RWStructuredBuffer<int> numDiffuseParticles` (u0, stride 4), `numDiffuseParticlesNew` (u1, stride 4)
- thread group 1x1x1, single invocation

## Algorithm
`numDiffuseParticles[0] = (int)min((float)kMaxDiffuseParticles, (float)numDiffuseParticles[0]);
numDiffuseParticlesNew[0] = 0;`
The clamp is performed in float (`itof`/`min`/`ftoi`), exactly as fxc emitted it.

## Inference
- `cb0[27].x` resolves to `kMaxDiffuseParticles` at offset 432 of the parameter block.
- The counter is reset for the next frame's diffuse emission pass.
