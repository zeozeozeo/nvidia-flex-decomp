# 064 `cs_5_0` — CalculateParticleHash

## Interface
- `cbuffer consts` (b0, 25 registers)
- `StructuredBuffer<int> activeIndices` (t0, 4), `StructuredBuffer<float4> newPositions` (t1, 16),
  `StructuredBuffer<float3> gBounds` (t2, 12)
- `RWBuffer<uint> cellHash` (u0), `RWBuffer<uint> cellIndices` (u1)
- thread group 256x1x1

## Algorithm
Per particle: read the active index, fetch the new position, subtract `gBounds[0]`, scale by
`kInvCellEdge` (`cb0[24].z`), truncate to int, and pack a 21-bit cell hash with 7 bits per axis
(`bfi` inserts at 0/7/14). Inactive lanes write `0xffffffff` to both outputs.

## Inference
- The three `bfi` operations are reconstructed as `(x << 14) + (y << 7) + z` over 7-bit masked
  coordinates; the exact field order follows the operand order in the SHEX (`r0.wwwz`).
- `gBounds` stride 12 is a single `float3` read at index 0.
- `bufi`/`ftoi`: HLSL `(int3)` cast reproduces the truncating conversion.
