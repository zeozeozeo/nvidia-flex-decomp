# 000 `cs_5_0` — BuildLeaves (NvFlexReleaseD3D_x64.dll)

## Interface
- `cbuffer constBVH { int gNumItems; }` (b0)
- `StructuredBuffer<float4> itemLowers` (t0), `itemUppers` (t1), `Buffer<uint> indices` (t2)
- `RWStructuredBuffer<int> rangeLefts` (u0), `rangeRights` (u1)
- `RWStructuredBuffer<lowersType/uppersType>` (u2/u3, 16-byte elements `{float x, y, z; uint ib}`)
- thread group 256x1x1

## Algorithm (from `000_cs_5_0.asm`)
For every item: `index = indices[tid]`; write `lowers[tid] = {itemLowers[index].xyz, index | 0x80000000}`
and `uppers[tid] = {itemUppers[index].xyz, index & 0x7fffffff}` (the high bit is the BVH leaf
flag, produced by `bfi(31,0,index,0x80000000)`), and `rangeLefts[tid] = rangeRights[tid] = tid`.

## Naming
Index 000 exists in both DLLs. The Ext DLL's shader is shipped source
(`000_cs_5_0__execute.hlsl`); this one is DLL-qualified as
`NvFlexReleaseD3D_x64.000_cs_5_0__BuildLeaves.hlsl` so both gates resolve independently
(`--dll NvFlexReleaseD3D_x64.dll --index 0` → 1/1, Ext DLL → 1/1).
