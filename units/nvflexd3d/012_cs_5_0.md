# 012 `cs_5_0` — ComputeTotalInvEdges

## Interface
- `StructuredBuffer<float3> totalLower` (t0, stride 12), `totalUpper` (t1, stride 12)
- `RWStructuredBuffer<float3> totalInvEdges` (u0, stride 12)
- thread group 1x1x1, single invocation

## Algorithm (from `012_cs_5_0.asm`)
`totalInvEdges[0] = 1 / (totalUpper[0] - totalLower[0] + 1e-4f)` per component.
The epsilon `0x38D1B717` (1e-4f) guards a degenerate BVH bound; it is added to the
unsigned edge length, so this is the reciprocal of the edge length with a floor.

## Inference
- Kernel name from the RDEF resource prefix (`ComputeTotalInvEdges`).
- The single-invocation launch is the asm's `dcl_thread_group 1, 1, 1`; the host
  dispatches one thread.
