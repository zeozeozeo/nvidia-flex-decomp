# 057 `cs_5_0` — SolveDensities (phase-aware)

## Interface
- `cbuffer consts` `cb0[24]` immediateIndexed
- SRV `t0`/`t1` 4 (`contacts`, `contactCounts`), `t2` 16 (`sortedNewPositions`), `t3` 4
  (`phases`), `t4` 4 (`densities`), `t6` 16 (`sortedPositions`), `t7` 16 (`sortedNormals`)
- UAV `u0` raw (`deltas`)
- thread group 256×1×1

## Algorithm
Two neighbour paths selected by `phase & (1<<22)` (solid):
- solid/solid: weight `(density_i + density_n) * (1 - dist*kInvRadius) * -kSpiky2`; when the
  phases differ the weight is used as-is, otherwise the plastic term
  `kCohesion * (kCohesion1*q³ + kCohesion2*q² - 1) + w` is added (`q = dist*kInvRadius`);
- otherwise the 044 path (neighbour normal selection, `kSolidRestDistance` rejection, friction
  with `kStaticFriction` / `kParticleFriction`).

`(delta.xyz, count)` is stored into the raw slot `tid*16`.

## Inferences
- `kInvRadius` = `cb0[8].w`, `kSpiky2` = `cb0[9].z`, `kCohesion1/2` = `cb0[10].y/.z`,
  `kCohesion` = `cb0[12].y` (matches the PDB `KernelParams` offsets).
- In the solid path `r5.xyz` (the cohesion push) is computed before the plastic variant and both
  start from the same accumulator.
