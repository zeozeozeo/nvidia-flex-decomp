# 041 `cs_5_0` — UpdateVertexNormals (clear pass)

## Interface
- `cbuffer consts` (b0, 26 registers)
- `RWByteAddressBuffer vertNormals` (u0, `dcl_uav_raw`)
- thread group 256x1x1

## Algorithm
`if (tid < kMaxParticles) vertNormals.Store4(tid * 16, 0);`
Clears one `float4` normal slot per particle before the accumulation pass.

## Inference
- The RDEF resource is `UpdateVertexNormals::vertNormals`; the kernel is the clear
  half of the vertex-normal update (the normalize half is shader 060).
- The bound is `cb0[25].y` = `kMaxParticles` (offset 404), not `kNumParticles`: the
  buffer is sized for the maximum particle count.
