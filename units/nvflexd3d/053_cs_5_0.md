# 053 `cs_5_0` — SpringsGenerateIndices

## Interface
- `cbuffer SpringsGenerateIndices::consts { uint gNumSprings; }` (b0)
- `RWBuffer<uint> indices` (u0, `dcl_uav_typed_buffer`)
- thread group 256x1x1

## Algorithm
`if (tid < 2 * gNumSprings) indices[tid] = tid;` — the identity permutation over the two
half-edges of every spring, used as the radix-sort payload.
