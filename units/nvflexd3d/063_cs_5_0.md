# 063 `cs_5_0` — CreateGrid

## Interface
- `cbuffer consts` (b0, 24 registers)
- `Buffer<uint> cellIds` (t0), `RWStructuredBuffer<int> cellStarts` (u0), `cellEnds` (u1)
- thread group 256x1x1

## Algorithm
Run-boundary scan over the sorted cell ids: `cellStarts[cellId] = i` at the first element
of a run and `cellEnds[prevCellId] = i` when a run ends; the last thread closes the final
run with `i + 1`. Direct port of `CreateGrid` (`flex.cu:740`).

## Inference
- The load is a typed buffer of `uint`; `cellId` is used as a structured-buffer index.
