# 062 `cs_5_0` — SolveDensities (phase-aware, normal-difference variant)

## Interface
- `cbuffer consts` `cb0[24]` immediateIndexed
- SRV `t0`/`t1` 4, `t2` 16, `t3` 4 (`phases`), `t4` 4 (`densities`), `t6` 16, `t7` 16
- UAV `u0` raw (`deltas`)
- thread group 256×1×1

## Algorithm
Identical to 057 except that the solid/solid plastic branch additionally removes the normal
difference `(sortedNormals[tid].xyz - sortedNormals[n].xyz)` from the pushed accumulator
(`add r12.xyz, r2.xyzx, -r9.xyzx` / `add r10.yzw, r10.yzw, -r12.xyzx` before the phase select),
and the neighbour normal (`r9`) is loaded once before the branch.

## Inferences
- Only the plastic variant carries the extra subtraction; the cohesion-only variant
  (`phase_i != phase_n`) is unchanged, matching the `movc` on `ine r10.x, r3.x, r10.x`.
