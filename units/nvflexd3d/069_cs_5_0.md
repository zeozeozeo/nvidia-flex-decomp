# 069 `cs_5_0` — CalculateVorticity

## Interface
- `cbuffer consts` (b0, 24 registers)
- `StructuredBuffer<float4> fluidPositions` (t0, 16), `fluidVelocities` (t1, 16),
  `StructuredBuffer<uint> particleFlags` (t2, 4), `neighbors` (t3, 4),
  `StructuredBuffer<int> neighborCounts` (t4, 4)
- `RWStructuredBuffer<float4> vorticity` (u0, 16)
- thread group 256x1x1

## Algorithm
Diffuse particles only (`phase & 0x400000`), otherwise the output is cleared and the shader
returns. For each diffuse neighbour inside `kRadiusSq`, accumulate
`cross(vj - vi, r * (1 - |r|/h) * -kSpiky2 / |r|)`; store `float4(w, |w|)`.

## Inference
- The bytecode's component-swizzled differences (`r0.zyxz`) are a consistent permutation of the
  same vector; the reconstruction uses the unpermuted vectors.
- Neighbour-list stride is `kNumParticlesAligned` (`cb0[23].y`).
- `cb0[8].z/.w` = `kRadiusSq`/`kInvRadius`, `cb0[9].z` = `kSpiky2` (offsets confirmed).
