# 067 `cs_5_0` — CalculateAnisotropy

## Interface
- `cbuffer consts` (b0, 24 registers)
- `Buffer<uint> indices` (t2, typed uint buffer), `StructuredBuffer<uint> particleFlags` (t3, 4),
  `neighbors` (t0, 4), `neighborCounts` (t1, 4), `StructuredBuffer<float4> positions` (t4, 16)
- `RWStructuredBuffer<float4> u0/u1/u2` (16) — the three anisotropy frame columns
- thread group 256x1x1

## Algorithm
Two passes over the neighbour list: (1) weighted centroid with `w = 1 - (d/h)^3`, only for
diffuse neighbours; (2) weighted covariance of the same set around the centroid, normalised by
the total weight. A four-sweep Jacobi eigen decomposition of the symmetric 3x3 follows; each
eigenvector is written with `clamp(sqrt(|lambda|) * kAnisotropy, kAnisotropyMin,
kAnisotropyMax)` in `w`. Degenerate neighbourhoods (`count < 0` or zero weight) write the
identity frame with `kAnisotropyMin`.

## Inference (recorded, not exact)
- The fabricated 3x3 Jacobi sweep (largest off-diagonal pivot, 4 fixed sweeps) reproduces the
  bytecode's control flow but the exact rotation-sign conventions are reconstructed, not proven.
- `cb0[13].y/.z/.w` = `kAnisotropy` / `kAnisotropyMin` / `kAnisotropyMax`; `cb0[8].z/.w` =
  `kRadiusSq` / `kInvRadius` (offsets confirmed against the RDEF variable table).
