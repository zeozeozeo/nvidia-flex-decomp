## Known recovered-header gap (reported, not edited)

`recon/include/nvflex/all.h` includes only `recovered.h`, which declares neither
`NvFlexSolverDesc`, `NvFlexCopyDesc` nor `NvFlexParams` (they live in the
public `NvFlex.h`). The differential harness generated by `flexkit gate diff`
therefore cannot spell those parameter types; the spec above uses ABI-equivalent
`void*` spellings, which is byte-for-byte identical at the ABI level.
